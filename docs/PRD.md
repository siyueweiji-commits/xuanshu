# 产品需求文档（PRD）：玄枢（XuanShu）

- **文档版本**：v1.0（最终版）
- **日期**：2026-09-30
- **项目代号**：玄枢 / XuanShu
- **定位**：开箱即用的离线命理应用
- **技术形态**：桌面应用（Windows / macOS / Linux）

---

## 1. 产品概述

### 1.1 一句话定位

**玄枢**是一款开箱即用的离线命理应用，集八字、紫微斗数、梅花易数、六爻等功能于一体，用户双击安装即可使用，无需服务器、无需数据库配置、无需命令行。应用日常可离线运行，具备联网条件时可后台访问开源公共数据源，自动更新历法、规则、知识库。

### 1.2 产品定位

- 文化娱乐工具
- 个人自省与生活提醒
- 命理学习与研究辅助
- 隐私优先：数据本地存储，不上传云端

**不是**：医疗、法律、投资、驾驶决策工具，不承诺预测准确性。

### 1.3 核心理念

- **开箱即用**：一个安装包，双击即用
- **离线优先**：断网也能完整使用
- **联网增强**：有网时自动更新数据源
- **数据自持**：所有数据在用户本地
- **规则透明**：规则库可查看、可修改、可导入导出

## 2. 目标与非目标

### 2.1 目标

1. 输入生辰信息，生成紫微斗数命盘、八字四柱。
2. 支持梅花易数起卦、六爻排盘。
3. 计算指定日期的流年、流月、流日、流时。
4. 通过规则引擎输出"今日注意事项"。
5. 用模板生成自然语言报告。
6. 支持用户记录实际事件，用于回测。
7. 规则、知识库、模板可维护、可导入导出。
8. 具备联网条件时，自动从 GitHub / 公共数据源更新历法、规则、知识库。
9. 打包为 Windows `.exe`、macOS `.dmg`、Linux `.AppImage`。

### 2.2 非目标

- 不做科学预测系统。
- 不做医疗、法律、投资建议。
- 不替代专业驾驶安全建议。
- 不保证"算得准"。
- 不依赖云服务器。
- 不做在线账户、云同步、社交功能（v1）。

## 4. 核心功能模块

### 4.1 用户与档案

- 本地单用户，无需注册登录
- 出生信息：公历/农历、年月日时、性别、出生地
- 真太阳时校正
- 多档案管理（为自己、家人、朋友建档）
- 档案导入/导出（JSON）

### 4.2 历法转换

- 公历 ↔ 农历
- 干支纪年、月、日、时
- 节气计算
- 真太阳时
- 黄历：宜忌、冲煞、彭祖百忌、神煞、建除十二神、二十八宿

### 4.3 紫微斗数

- 命宫、身宫、十二宫
- 十四主星、辅星、煞星
- 四化（禄权科忌）
- 大限、流年、流月、流日、流时
- 流日斗君算法
- 命盘导出（图片 / PDF / JSON）

### 4.4 八字

- 四柱排盘
- 十神、五行强弱
- 大运、流年、流月、流日
- 神煞
- 命盘导出

### 4.5 梅花易数

- 时间起卦
- 数字起卦
- 报数起卦
- 体用分析
- 互卦、变卦、错卦、综卦
- 卦象解读（规则库驱动）

### 4.6 六爻

- 铜钱起卦（模拟）
- 手动录入爻
- 装卦：纳甲、六亲、六神、世应
- 动爻、变卦
- 卦象解读（规则库驱动）

### 4.7 流日运势与提醒

- 选择日期，查看流日盘
- 输出：流日命宫、四化、黄历宜忌
- 规则引擎输出 3～10 条注意事项
- 报告分类：事业、财运、人际、健康、出行

### 4.8 报告生成

- 模板拼接生成基础报告
- 可选 LLM 润色（离线小模型，插件化，v2 考虑）
- 必须由规则库约束，防止胡说
- 每次报告附免责声明

### 4.9 反馈与回测

- 用户记录实际事件：罚单、破财、争吵、生病、好事等
- 事件与日期、命盘关联
- 回测：规则命中率统计
- 用户可查看历史记录
- 数据仅本地存储

### 4.10 数据更新（联网增强）

- 检查 GitHub 仓库更新
- 更新历法数据、规则库、知识库、模板
- 支持手动触发更新
- 支持关闭自动更新
- 更新失败不影响离线使用
- 更新源可配置

### 4.11 设置

- 真太阳时开关
- 自动更新开关
- 数据目录查看
- 数据导出/导入
- 数据清除
- 主题（浅色/深色）
- 语言（中文，v2 考虑多语言）

### 4.12 免责与合规

- 首次启动显示免责声明
- 每次报告附免责声明
- 不提供医疗/法律/投资建议
- 隐私政策：数据本地、不上传
- 用户可删除全部数据

## 5. 数据来源与更新机制

### 5.1 离线数据（打包在安装包内）

- 历法基础数据
- 紫微斗数安星规则
- 八字排盘规则
- 梅花易数、六爻规则
- 规则库 JSON
- 知识库 JSON
- 报告模板
- 城市经纬度

### 5.2 联网更新数据（可选）

| 数据来源 | 来源 |
| --- | --- |
| 历法修正 | 开源天文历法库（sxtwl、lunar-python 等）的 GitHub Release |
| 规则库 | 你自己的 GitHub 仓库 `xuanshu-data` |
| 知识库 | 你自己的 GitHub 仓库 `xuanshu-data` |
| 报告模板 | 你自己的 GitHub 仓库 `xuanshu-data` |
| 城市经纬度 | 公开数据集 |

### 5.3 更新机制

- 应用启动时或定时检查更新
- 通过 GitHub Raw / GitHub Release 下载
- 校验文件哈希
- 更新到用户数据目录，不覆盖安装目录
- 更新失败回滚
- 用户可手动触发
- 用户可关闭自动更新
- 更新源可在设置中配置（默认指向你的仓库）

### 5.4 不依赖服务器

- 所有更新走 GitHub 静态文件
- 不需要自建服务器
- 不需要域名
- 不需要 HTTPS 证书管理

## 7. 数据模型（SQLite）

- **profiles**：id、name、gender、birth_time、birth_location、is_default、created_at
- **charts**：id、profile_id、type（ziwei/bazi）、data_json、created_at
- **daily_fortunes**：id、profile_id、date、chart_json、advice_json、created_at
- **divinations**：id、profile_id、type（meihua/liuyao）、question、data_json、created_at
- **feedbacks**：id、profile_id、date、event_type、description、created_at
- **settings**：key、value
- **update_logs**：id、source、status、message、created_at

规则库、知识库、模板以 JSON 文件形式存放，不强制入数据库。

## 8. 规则库设计

```json
{
  "id": "ziwei_travel_warning",
  "system": "ziwei",
  "condition": {
```

### 8.2 规则分类

## 13. 风险

1. 命理无科学依据，不能宣称预测。
2. 开源库维护风险，需锁定版本。
3. GitHub 访问不稳定，需镜像/代理方案。
4. 更新失败可能影响体验，需回滚。
5. 用户期望过高，需明确免责。
6. 本地 LLM 体积大，v1 不做。
